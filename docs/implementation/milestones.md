# Milestones

| Milestone | Exit evidence | Relative timing |
|---|---|---|
| M0 Plan approved | Owner decisions resolved; target segment and MVP accepted | Before code |
| M1 Foundation runnable | CI, Compose, API/web shells, health/docs | 3–5 weeks after kickoff |
| M2 Secure tenant baseline | Auth, org, RBAC, branches/warehouses, isolation suite | 3–5 weeks |
| M3 Catalog and inventory core | Product catalog, immutable ledger, counts, transfers, reorder | 5–8 weeks |
| M4 Buy and receive | PO and idempotent partial receipt | 3–5 weeks |
| M5 Sell and fulfill | Reservation, partial fulfillment, invoice/payment records | 4–7 weeks |
| M6 Reports and pilot quality | Core reports, exports, E2E, restore/security drill | 4–7 weeks |
| M7 Controlled pilot | Real device/user validation and feedback | 2–4 weeks |
| M8 Production launch | Local compliance/accounting review and readiness approval | Depends on review |

Ranges overlap and assume an experienced small team; not a commitment. Tasks and external reviews determine actual schedule.
